# GotIt 本地视频下载工具

本地开发版：粘贴抖音分享文案，解析来源视频，下载到当前电脑。

**当前状态：已用用户提供的视频链接验证真实解析与下载。**
2026-10-02，普通分享页缺少视频数据的问题通过独立 Chrome 备用解析解决。视频 `7689028070339043685` 已下载：1,965,734 字节，约 9.37 秒，1280×720，H.264 视频及 AAC 音频；FFmpeg 完整解码通过。单条成功不代表所有链接都可用，也不保证去除画面内嵌水印。之前六个样例仅在普通 HTTP 解析路径下失败，尚未逐条重新验收。

内置浏览器自动化曾发生环境错误；后改用独立 Chrome 验收。已从本地网页粘贴用户完整分享文案，成功解析、提交下载并预览视频，浏览器报告 1280×720、9.37 秒、无播放错误。页面截图已检查。

## 启动

需要 Python 3.10 或更新版本及本机 Google Chrome。macOS 双击仓库根目录的 `start.command`；首次使用会建立虚拟环境并安装 FastAPI、Uvicorn、Playwright。浏览器备用解析使用已安装的 Chrome，无需另外下载 Chromium。

也可以在仓库根目录运行：

```sh
./start.command
```

浏览器打开 <http://127.0.0.1:8765>。终端按 Ctrl+C 停止。文件保存在仓库根目录的 `downloads/`，不会自动删除已完成的视频。

首期只监听本机，不支持手机局域网访问；不要将当前版本直接开放到公网。

## 已实现

- 从分享文案提取抖音短链接、视频长链接。
- 读取移动分享页的公开 `_ROUTER_DATA` 视频信息。
- 分享页缺少数据时，启动全新、无登录的独立浏览器上下文，加载公开视频，选取 `__vid` 与目标作品 ID 一致的播放地址；排除预加载片段及推荐视频。结束后关闭浏览器，不访问日常浏览器资料或持久化登录态。
- 创建下载任务、单任务顺序处理、最多三个待处理任务。
- 流式下载、显示进度、200MB 上限、五分钟下载时限。
- MP4 文件头及长度检查，失败清理临时文件，完成后改名。
- 下载历史、重复下载识别、本地预览、另存文件。
- 每条已下载视频支持“打开文件位置”，在 macOS Finder 中选中对应文件；文件已移动或删除时提示错误。
- 过期解析结果拒绝使用，403/410 时重新解析一次。
- 域名限制、每次跳转检查、DNS 公网地址检查、连接 IP 固定及 HTTPS 证书验证。
- 上述连接 IP 固定适用于 HTTP 页面和文件下载。浏览器备用路径单独限制资源域名、检查公网 DNS、禁用 Service Worker；Chrome 自身管理实际连接，不承诺同等的 IP 固定。
- 页面会话校验、Host 校验；不使用浏览器 Cookie，不调用付费 API。

## 限制

- 获取的是来源播放文件，不做 AI 画面修复，不保证无内嵌水印。
- 平台可能不返回公开数据；遇到验证提示不会尝试处理验证码。
- 暂不支持图集、直播、私密视频、批量下载及其他平台。
- 图文分享短链及 `/note/`、`/share/note/` 长链会明确提示“图文作品”，不会再误报为主页、直播或合集。
- MP4 文件头检查不等同于完整解码验证；本次真实样例另行通过 FFmpeg 完整解码，程序不会为每个下载文件自动调用 FFmpeg。
- 为固定公网目标地址，出站连接不读取系统 HTTP(S) 代理环境变量；必须能直接访问来源站点。
- DNS 查询依赖系统解析器；网络读取有超时，系统 DNS 自身的阻塞时间不由应用控制。
- 没有下载取消和自动删除已完成文件功能。退出时等待当前下载结束或超时。

## 测试

```sh
.venv/bin/python -m pip install -r app/requirements-dev.txt
PYTHONPATH=app .venv/bin/python -m pytest app/tests -q
```

`requirements-lock.txt` 记录本次验证环境（含测试工具）的精确版本；跨 Python 版本使用时仍需确认依赖兼容。

测试覆盖非法域名、内网 DNS、危险跳转、页面数据解析、下载成功、重复下载、错误网页、超限、截断、空文件、失败清理、会话和任务恢复。成功路径为离线模拟，不将模拟数据放入用户的下载列表。

## 目录

- `gotit/parser.py`：可替换的解析适配器。
- `gotit/browser.py`：独立 Chrome 备用解析，不使用日常浏览器登录信息。
- `gotit/network.py`：受限 HTTPS 客户端。
- `gotit/jobs.py`：下载任务及本地记录。
- `gotit/server.py`：本地接口。
- `gotit/static/`：网页。
- `tests/`：自动化测试。
