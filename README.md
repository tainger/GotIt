# GotIt

自用的本地短视频下载工具。粘贴抖音分享文案，解析并保存视频到电脑。

## 快速开始

需要 Python 3.10+ 和 Google Chrome。

macOS 双击 `start.command`，或在项目目录运行：

```sh
./start.command
```

首次启动会安装依赖。打开 <http://127.0.0.1:8765/> 即可使用。

## 功能

- 分享文案和短链接解析；必要时使用独立 Chrome 加载公开视频。
- 下载进度、历史记录、视频预览、另存文件。
- 在 macOS Finder 中打开文件位置。
- 文件保存到本机 `downloads/`，无需云服务器或付费接口。

目前仅支持公开单条抖音视频，不支持图文、直播或私密内容。平台变动可能导致解析失败；下载来源播放文件，不保证去除画面内嵌水印。请仅保存你拥有或获准使用的内容。

程序仅监听本机地址。浏览器解析使用独立临时上下文，不读取日常浏览器登录信息。

详细运行说明、限制、架构与测试参见 [app/README.md](app/README.md)。
